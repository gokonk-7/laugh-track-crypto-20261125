One crypto/trading joke (143 characters) for make.fun's "Laugh Track: The Crypto Trading Joke Contest". A judge model compares the entries two at a time and keeps the funnier one — so instead of another dip-buying or stop-loss joke, this entry takes the self-custody angle: the safest wallet in crypto is the one even its owner cannot open.

> I keep my seed phrase on paper so hackers can't steal it. I lost the paper — so now it's the most secure wallet in crypto: even I can't get in.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # or output/entry.txt when /output is absent
```

`main.py` writes the joke to `/output/entry.txt` when that directory exists (the grader's sandbox), and to `output/entry.txt` beside the script otherwise; it prints the path it used. The gate requires UTF-8 text of 1 to 200 characters; the entry is 143.
